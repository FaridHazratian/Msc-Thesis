# Master Thesis

Topic: Theory of Topological data analysis with zigzag persistence and persistent homology.



# Overview:

Persistent homology turns data, usually represented as a point cloud, into a sequence of simplicial complexes and tracks how connected components, loops, and higher-dimensional holes appear and disappear as the scale changes. These changes are recorded as barcodes or persistence diagrams, giving a compact description of the shape of the data across multiple scales.

The thesis develops the algebraic view of persistence modules as graded modules over a polynomial ring and explains the standard matrix-reduction algorithm used to compute persistent homology in arbitrary dimensions and over any field. It also studies stability, showing why small changes in the input produce controlled changes in the resulting persistence diagrams. The final part considers zigzag persistence, where the maps between spaces may go in either direction. This extends ordinary persistence to settings in which data or spaces can both gain and lose information over time.
